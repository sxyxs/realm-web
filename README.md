# REALM project page

Static project page for *From Region Arrival to Instance-Level Grounding in Vision-and-Language Navigation* (CoRL 2026 Spotlight).

## Deploy on GitHub Pages
1. Create a repo, e.g. `sxyxs/realm` (the page will be at `https://sxyxs.github.io/realm/`).
2. Push everything in this folder to the `main` branch.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
